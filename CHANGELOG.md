# История изменений

## 1.1.0 — 2026-08-21

- добавлена автономная локальная BPMN-студия на встроенном `bpmn-js`: создание,
  открытие, сохранение и проверка схемы мышью, без знания XML и командной строки;
- добавлен запуск одним файлом `ОТКРЫТЬ-BPMN-РЕДАКТОР.cmd` с проверкой версии
  Node.js и автоматической установкой зависимостей;
- добавлен адаптер Archify: человекочитаемая карта строится из BPMN внутри
  Студии и помечается устаревшей после изменения исходной схемы;
- добавлен локальный MCP-сервер: те же операции доступны Codex, Claude, Cursor
  и другим совместимым агентам, при этом агент не может утвердить процесс;
- добавлены переходы между процессами через стандартный `Call Activity` с
  тремя честными состояниями цели: готовый процесс, будущий процесс, `unresolved`;
- добавлена лицензия MIT в корень проекта;
- добавлена автоматическая проверка в GitHub Actions наравне с GitLab CI;
- удалён незавершённый черновой пакет `processes/vydach`, оставшийся от проверки
  мастера создания процесса;
- документы о связях между процессами разделены по назначению и связаны
  перекрёстными ссылками: выбор вида связи и техническая настройка перехода.

## 1.0.0 — 2026-08-20

- добавлен эталонный процесс «Скупка золота и драгоценных металлов»;
- добавлены человекочитаемая карта, карточка процесса и нейтральный BPMN 2.0;
- внутренние коды шагов заменены смысловыми техническими идентификаторами;
- добавлены шаблон нового процесса, реестр межпроцессных переходов и правила интеграции с движками;
- переходы вызова синхронизированы через смысловые `calledElement` и идентификаторы целевых процессов;
- интерактивная карта полностью локализована на русский язык и не загружает внешние шрифты;
- добавлена воспроизводимая проверка XML, схем, рендера, русской карты и навигации.
- проверка реестра автоматически охватывает каждый добавленный процесс, а ссылки шаблона остаются внутри его скопированного пакета.
