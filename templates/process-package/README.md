# Шаблон нового бизнес-процесса

Скопируйте эту папку в `processes/<короткое-название>` и заполните файлы по порядку:

1. `process-card.md` — смысл, границы, роли, маршрут и вопросы.
2. `map/process-map.md` — короткая карта для человека.
3. `bpmn/process.bpmn` — подробная нейтральная схема.
4. `bpmn/process.meta.json` — версия, статус и переходы.
5. `bpmn/questions.json` — вопросы владельцу.
6. `bpmn/decisions.json` — только фактически принятые решения.
7. `evidence/README.md` — основания и границы доказанности.

После копирования замените `PROCESS-TEMPLATE`, `Process_Template` и «Новый бизнес-процесс» на смысловые значения. Ссылки `../process-card.md` и `../evidence/README.md` уже указывают внутрь скопированного пакета — не заменяйте их путями к исходному шаблону. Обновите хеши командой `refresh-package-hashes.mjs` и зарегистрируйте процесс в `registry/processes.json`.
