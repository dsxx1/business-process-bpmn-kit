# Новый бизнес-процесс

## Зачем нужен процесс

Опишите бизнес-результат одним абзацем.

## Когда начинается

Укажите наблюдаемое событие, которое запускает работу.

## Когда заканчивается

Перечислите успешный результат и отдельные неуспешные исходы.

## Кто участвует

- инициатор;
- исполнитель;
- согласующий;
- получатель результата.

## Основной маршрут

1. Уточнить входные данные.
2. Проверить возможность выполнения.
3. Выполнить работу.
4. Проверить результат.
5. Передать результат получателю.

## Исключения

- входные данные неполны;
- выполнение невозможно;
- результат требует исправления;
- работа завершена без результата.

## Открытые вопросы

- Кто является владельцем процесса?
- Каким фактом подтверждается успешное завершение?
- Какие сроки, полномочия и контрольные точки обязательны?
