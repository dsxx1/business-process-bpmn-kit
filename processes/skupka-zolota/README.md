# Скупка золота и драгоценных металлов

Это эталон оформления одного бизнес-процесса в двух синхронизированных видах:

- [простая карта PNG](map/process-map.png) — быстро понять маршрут прямо в GitLab;
- [подробная BPMN-схема SVG](bpmn/derived/process.svg) — разобрать развилки и исключения прямо в GitLab;
- [интерактивная карта](map/process-map.html) — локально исследовать маршрут после скачивания проекта;
- [BPMN-навигатор](bpmn/derived/process-navigation.html) — локально переходить в связанные процессы;
- [карточка процесса](process-card.md) — увидеть цель, границы, роли и нерешённые вопросы;
- [исходный BPMN](bpmn/process.bpmn) — передать разработчику.

Техническая модель проверена. Бизнес-содержание пока ожидает решения владельца по открытым вопросам, поэтому это рабочая модель, а не утверждённый регламент.
